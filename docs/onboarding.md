# Spa-Flow New Staff Onboarding Checklist

**Last Updated:** May 22, 2026  
**Version:** 1.0

This checklist guides new staff members through the onboarding process for Spa-Flow. Complete each item and have your manager sign off when finished.

---

## Pre-Onboarding

### Before First Day

- [ ] Manager creates staff user account
- [ ] Manager assigns role (STAFF or MANAGER)
- [ ] Manager shares temporary password
- [ ] Manager provides Spa-Flow URL
- [ ] Manager schedules training sessions
- [ ] Manager assigns mentor (if applicable)

### Equipment Setup

- [ ] Computer with internet access provided
- [ ] Compatible browser installed (Chrome, Firefox, Safari, or Edge)
- [ ] Square terminal access (if applicable)
- [ ] Phone for SMS notifications (if applicable)
- [ ] Workspace assigned

---

## Day 1: Account Setup and Basics

### Account Setup

- [ ] Log in with temporary password
- [ ] Change password to a secure one (minimum 15 characters)
- [ ] Verify email address is correct
- [ ] Review dashboard overview
- [ ] Understand session expiry (15 minutes inactive)

### System Overview

- [ ] Read User Manual (docs/user-manual.md)
- [ ] Review Quick Reference Guide (docs/quick-reference.md)
- [ ] Understand resource status colors (green, red, yellow)
- [ ] Learn navigation menu structure
- [ ] Review security best practices

### Basic Navigation

- [ ] Navigate to Dashboard
- [ ] Navigate to Check-In page
- [ ] Navigate to Clients page
- [ ] Navigate to Lockers page
- [ ] Navigate to Rooms page
- [ ] Navigate to Waitlist page
- [ ] Navigate to Products page
- [ ] Navigate to Transactions page
- [ ] Navigate to Sessions page

### Manager Only (if applicable)

- [ ] Navigate to Reports page
- [ ] Navigate to Users page
- [ ] Navigate to Audit Logs page

---

## Day 2: Client Management

### Client Creation

- [ ] Practice creating a new client profile
- [ ] Fill in all required fields correctly
- [ ] Add optional fields (address, document number)
- [ ] Verify client appears in search
- [ ] Practice updating client information

### Client Search

- [ ] Search by name
- [ ] Search by email
- [ ] Search by phone number
- [ ] Search by member ID
- [ ] View client detail page
- [ ] Review client rental history
- [ ] Review client transaction history

### Memberships

- [ ] Add one-time membership to client
- [ ] Add six-month membership to client
- [ ] Process membership payment
- [ ] Verify membership status updates
- [ ] Understand membership pricing

### Shadowing

- [ ] Shadow mentor during client interactions
- [ ] Observe client information verification
- [ ] Observe membership sales process
- [ ] Ask questions about client management

---

## Day 3: Check-In Process

### Check-In Flow

- [ ] Practice complete check-in flow
- [ ] Search for existing client
- [ ] Create new client during check-in
- [ ] Select resource type (locker/room)
- [ ] Choose specific resource
- [ ] Process payment (Square, cash, card)
- [ ] Confirm assignment
- [ ] Verify resource status changes

### Payment Processing

- [ ] Process Square terminal payment
- [ ] Process cash payment
- [ ] Process card payment
- [ ] Handle payment failures
- [ ] Understand pricing calculations
- [ ] Verify tax is applied correctly

### Shadowing

- [ ] Shadow mentor during check-ins
- [ ] Observe payment processing
- [ ] Observe client communication
- [ ] Practice check-in with mentor supervision

---

## Day 4: Resource Management

### Locker Management

- [ ] Assign locker to client
- [ ] Release locker
- [ ] Renew locker session (6 hours)
- [ ] Extend locker session (2 hours)
- [ ] Practice bulk release
- [ ] Verify locker status accuracy

### Room Management

- [ ] Assign room to client
- [ ] Release room
- [ ] Renew room session (6 hours)
- [ ] Extend room session (2 hours)
- [ ] Practice bulk release
- [ ] Verify room status accuracy

### Resource Status

- [ ] Understand resource status colors
- [ ] Monitor occupancy levels
- [ ] Release resources promptly
- [ ] Handle resource status discrepancies

### Shadowing

- [ ] Shadow mentor during resource management
- [ ] Observe release procedures
- [ ] Observe renewal/extension process
- [ ] Practice with mentor supervision

---

## Day 5: Waitlist Management

### Waitlist Operations

- [ ] View waitlist positions

- [ ] Test SMS notification
- [ ] Understand notification timing
- [ ] Handle notification failures

### Shadowing

- [ ] Shadow mentor during waitlist management
- [ ] Observe assignment confirmation
- [ ] Observe SMS notification process
- [ ] Practice with mentor supervision
