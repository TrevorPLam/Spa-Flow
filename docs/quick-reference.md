**Last Updated:** May 22, 2026  
**Version:** 1.0

## Common Tasks

### Check-In a Client
1. Go to **Check-In** page
2. Search for client (or create new)
3. Select resource type (Locker/Room)
4. Choose specific resource
5. Process payment
6. Confirm assignment

### Create New Client
1. Go to **Clients** page
2. Click **New Client**
3. Fill in: First Name, Last Name, Email, Phone, DOB
4. Click **Create Client**

### Assign Locker
1. Go to **Lockers** page
2. Click available locker (green)
3. Select client
4. Click **Assign**
5. Process payment

### Release Locker
1. Go to **Lockers** page
2. Click occupied locker (red)
3. Click **Release**
4. Confirm

### Renew Session (6 hours)
1. Go to **Lockers** or **Rooms** page
2. Click occupied resource
3. Click **Renew**
4. Process payment

### Extend Session (2 hours)
1. Go to **Lockers** or **Rooms** page
2. Click occupied resource
3. Click **Extend**
4. Process payment

### Add to Waitlist
1. Go to **Waitlist** page
2. Click **Add to Waitlist**
3. Search/create client
4. Click **Add to Waitlist**

### Confirm Waitlist Assignment
1. Go to **Waitlist** page
2. Click **Confirm** next to client
3. Client has 15 minutes to respond

## Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| Page not loading | Refresh page (F5) |
| Can't log in | Check password, wait 15 min if locked out |
| Payment failed | Check Square terminal, try again |
| Resource not available | Check waitlist, assign when available |
| Client not found | Create new client profile |
| System slow | Check internet connection |

## Password Requirements

- **Minimum length:** 15 characters
- **No composition rules** (no special character requirements)
- **Change on first login** for new accounts

---

## Security Best Practices

- Never share your password
- Log out when done for the day
- Lock screen when stepping away
- Report suspicious activity immediately
- Use strong, unique passwords
